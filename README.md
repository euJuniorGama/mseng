# MS Engenharia — site institucional

Site estático de página única (landing page) da MS Engenharia (Timbó/SC).

## Conteúdo
- `index.html` — página completa (HTML + CSS + SVG inline, sem dependências externas além do Google Fonts).

## Publicar
Qualquer host de site estático serve (GitHub Pages, Netlify, Vercel). Para GitHub Pages:
1. Settings → Pages → Deploy from a branch → branch `main`, pasta `/ (root)`.
2. O site fica em `https://<usuario>.github.io/mseng/`.
